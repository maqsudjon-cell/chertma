# uz-alphabet-bench

> **DRAFT — NOT PUBLISHED.** Every item is waiting for review by hand
> (`bench/review.md`). No Hugging Face repository exists. The numbers and
> examples below describe the draft, not a release.

**English** · [Oʻzbekcha](#oʻzbekcha)

## Motivation

In September 2026 Uzbekistan replaced four letters of its Latin alphabet:
`sh ch oʻ gʻ` became `ş ç ö ğ`. Text will exist in three scripts — Cyrillic,
old Latin, new Latin — for years, and every Uzbek language model, keyboard,
transliteration tool and publisher migrating an archive needs to handle all
three. There was no public evaluation set for the new alphabet. This is one.

It also measures something other benchmarks do not: whether a system leaves
alone what it should leave alone. The `preserve` category holds dialect,
slang and contractions whose correct treatment is *no change*.

## Format

JSONL, mirroring `tahrirchi/uzlib`:

```json
{"id": "ASC0000", "category": "ascii2new", "context": null,
 "question": "\"boling\" so'zining yangi alifbodagi to'g'ri shakli qaysi?",
 "options": ["boling", "böling", "boʻling", "bölinğ"], "answer": 1}
```

## Categories

| Category | Target | Tests |
|---|---|---|
| `ascii2new` | 100 | a word typed in bare ASCII → its new-Latin spelling |
| `old2new` | 80 | old Latin (`toʻgʻri`) → new Latin (`töğri`) |
| `cyr2new` | 80 | Cyrillic (`тўғри`) → new Latin |
| `preserve` | 100 | dialect, slang, contractions that must not change; the answer is `o'zgarmaydi` |
| `ambiguity` | 60 | minimal pairs resolved by sentence context |
| `apostrophe` | 40 | the tutuq `ʼ` (U+02BC) against look-alikes `ʻ` `’` and none |
| `edge` | 40 | `ng` + `ğ`, word-initial `е` → `ye`, `ts`, proper nouns |

Splits: `dev.jsonl` 50 items (answers public, for calibration), `test.jsonl` 450.

## Construction

Items are drafted by `tools/build_benchmark.py` from:

- the Chertma lexicon, built from `tahrirchi/uz-books-v2` (MIT) and
  `tahrirchi/uz-crawl` (Apache-2.0) — word choice and frequency;
- the conversion rules in Chertma's `docs/SPEC.md` — correct spellings and
  systematically wrong distractors (a mark removed, a mark added where none
  belongs, the old-Latin spelling);
- the examples in the project brief, for `preserve`.

**Every item is reviewed by hand before release.** Items marked `drop` are
removed; items marked `fix` are corrected by the reviewer. A linguistic
benchmark that a model generated and nobody checked is worse than none.

## Known limitations

- Distractors are generated by rule, so some are implausible spellings no
  person would write.
- The `preserve` draft contains generated forms (unknown words from Telegram
  channel posts) until the reviewer's hand-written dialect forms replace them.
- `ambiguity` is empty in this draft: its minimal pairs are still under review.
- Spellings follow Chertma's rules where the new orthography is not yet
  settled — Cyrillic `ъ` after a vowel, `ўъ`, a vowel before `и` are excluded
  from `cyr2new` until decided.
- Single words, mostly. Real text also mixes scripts inside a sentence.

## Oʻzbekcha

> **QORALAMA — EʼLON QILINMAGAN.** Har bir savol qoʻlda tekshirilishi kutilmoqda
> (`bench/review.md`). Hugging Face’da hech narsa joylanmagan.

**Nima uchun.** 2026-yil sentabrda oʻzbek lotin alifbosidagi toʻrt harf
almashdi: `sh ch oʻ gʻ` oʻrniga `ş ç ö ğ`. Yillar davomida matnlar uch yozuvda
— kirill, eski lotin, yangi lotin — boʻladi. Yangi alifbo uchun ochiq baholash
toʻplami yoʻq edi. Bu — shunday toʻplam. U tizim nimaga *tegmasligi* kerakligini
ham oʻlchaydi: `preserve` boʻlimidagi sheva, jargon va qisqartmalar oʻzgarmasligi kerak.

**Tuzilishi.** Savollar Chertma lugʻati (`tahrirchi/uz-books-v2`, MIT;
`tahrirchi/uz-crawl`, Apache-2.0) va imlo qoidalaridan tuziladi; notoʻgʻri
javoblar qoida asosida yasaladi (belgi olib tashlangan, ortiqcha belgi qoʻyilgan,
eski lotin yozuvi). **Har bir savol eʼlon qilinishidan oldin qoʻlda tekshiriladi.**

**Boʻlimlar:** `ascii2new` (100), `old2new` (80), `cyr2new` (80), `preserve` (100),
`ambiguity` (60), `apostrophe` (40), `edge` (40). Boʻlinish: `dev` 50, `test` 450.

**Cheklovlar:** notoʻgʻri variantlar qoida bilan yasalgani uchun baʼzilari
gʻalati koʻrinadi; `preserve` qoralamasida hozircha avtomatik tanlangan soʻzlar
bor; `ambiguity` hali tekshiruvda; imlosi hali hal boʻlmagan hollar
(`ъ`, `ўъ`, unli + `и`) `cyr2new`dan chiqarilgan.
