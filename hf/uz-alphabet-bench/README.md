# uz-alphabet-bench

**English** · [Oʻzbekcha](#oʻzbekcha)

An evaluation set for the 2026 Uzbek Latin alphabet: can a system write Uzbek
correctly in the new letters — and does it leave alone what it should leave alone?

## Why

In September 2026 Uzbekistan replaced four letters of its Latin alphabet:
`sh ch oʻ gʻ` became `ş ç ö ğ`. For years Uzbek text will exist in three scripts at
once — Cyrillic, the old Latin alphabet and the new one. Language models, keyboards,
transliteration tools and publishers converting archives all need to handle the
change, and there was no public evaluation set for it.

The set also measures something other benchmarks do not: restraint. The `preserve`
category holds dialect forms, slang and contractions whose correct treatment is **no
change**. A system that "corrects" `kelaslar` into `kelasizlar` has flattened how
people write.

## Format

JSON Lines, in the same shape as `tahrirchi/uzlib`, so existing multiple-choice
harnesses can read it:

```json
{"id": "ASC0000", "category": "ascii2new", "context": null,
 "question": "\"boling\" so'zining yangi alifbodagi to'g'ri shakli qaysi?",
 "options": ["boling", "böling", "boʻling", "bölinğ"], "answer": 1}
```

`answer` is the 0-based index of the correct option. Questions are in Uzbek (old
Latin). `context`, when present, is a sentence with the tested word replaced by `____`.

## How it was built

Draft items were generated from the word frequencies of
[`tahrirchi/uz-books-v2`](https://huggingface.co/datasets/tahrirchi/uz-books-v2) (MIT) and
[`tahrirchi/uz-crawl`](https://huggingface.co/datasets/tahrirchi/uz-crawl) (Apache-2.0),
through the conversion rules of the [Chertma](https://github.com/maqsudjon-cell/chertma)
project. Wrong options are built by rule: a mark removed, a mark added where none
belongs, the old-Latin spelling, a morphological "correction". `preserve` items are
hand-written forms.

**Every item was reviewed by hand before release.** Items that were wrong, ambiguous
or implausible were fixed or removed. Review: PLACEHOLDER (who, when).

## How to evaluate

`run_eval.py` in this repository scores a system and prints accuracy per category:

```bash
python run_eval.py --dataset Maqsudjonpolatov/uz-alphabet-bench --split test --backend api --endpoint https://…/v1/chat/completions --model NAME
python run_eval.py --items test.jsonl --backend hf --model ORG/MODEL
python run_eval.py --items test.jsonl --backend chertma --chertma-repo path/to/chertma
```

The `api` backend reads the key from `EVAL_API_KEY`. The prompt shows the question and
lettered options and asks for a letter only. Report accuracy on `test`.

## Known limitations

- Wrong options are generated by rule; some are spellings nobody would type.
- Mostly single words. Real text mixes scripts inside a sentence.
- Where the 2026 orthography is not settled — Cyrillic `ъ` after a vowel, `ўъ`, a
  vowel before `и` — items were excluded rather than guessed.
- One correct spelling per item; regional spelling variants are not credited.
- PLACEHOLDER (limitations found during review).

## Oʻzbekcha

2026-yilgi oʻzbek lotin alifbosi uchun baholash toʻplami: tizim yangi harflarda
toʻgʻri yoza oladimi — va oʻzgarmasligi kerak boʻlgan narsaga tegmay qoladimi?

### Nima uchun

2026-yil sentabrda oʻzbek lotin alifbosidagi toʻrt harf almashtirildi: `sh ch oʻ gʻ`
oʻrniga `ş ç ö ğ`. Yillar davomida oʻzbekcha matn bir vaqtning oʻzida uch yozuvda
boʻladi: kirill, eski lotin va yangi lotin. Til modellari, klaviaturalar,
transliteratsiya dasturlari va arxivini oʻgirayotgan nashriyotlar bu oʻzgarishni
toʻgʻri bajarishi kerak — lekin buni tekshiradigan ochiq toʻplam yoʻq edi.

Toʻplam boshqa benchmarklar oʻlchamaydigan narsani ham oʻlchaydi: `preserve` boʻlimidagi
sheva shakllari, jargon va qisqartmalar **oʻzgarmasligi** kerak. `kelaslar` soʻzini
`kelasizlar` qilib „toʻgʻrilagan” tizim odamlarning yozish uslubini yoʻq qiladi.

### Format

JSON Lines, `tahrirchi/uzlib` bilan bir xil tuzilishda. `answer` — toʻgʻri variantning
0 dan boshlanadigan tartib raqami. `context` boʻlsa, unda tekshirilayotgan soʻz oʻrnida
`____` turadi.
